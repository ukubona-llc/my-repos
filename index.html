Structural Observations · Pattern Read

⚡ HTML Dominance

This is a publishing-first architecture, not backend-first. Almost every repo is HTML — the interface and narrative are the primary deliverable. Private repos hold the execution layer. Public repos = interface + narrative + legitimacy.

⏱ Temporal Clustering

The "yesterday" cluster (npa-00 → npa-05 + debbie-concept) reveals a batch-release pattern — conceptual layers are developed in rapid bursts, not drip-fed. This is how the NPA spine grew.

🏛️ NPA Stack is the Spine

Six NPA repos (00 → 05) plus the demo form the central policy engine. Everything else orbits it. The NPA stack is the proof-of-concept the entire architecture was built to justify.

🔒 Private Repos = Execution

The public/private split is deliberate and architectural. Public repos do legitimacy and narrative. Private repos hold twins, pipelines, and internal logic. The interface is open; the engine is sovereign.

5 Clusters Emerging

Health + Clinical · NPA / Policy · Conceptual / Narrative · Infra / Twin / Ops · Meta / Experimental. Five clusters mapping cleanly onto the pentadic L₁–L₅ structure. This is not accidental. The repo ecosystem is the OS.

📊 Strategic vs Scaffolding

Highest strategic weight: hmis, npa-03, npa-demo, ckd, renal-atlas, sgd-theology, la-distincion. Pure scaffolding: repos-00, repo-01, sham-00, y26m01d28, source-code. The conceptual layer (narrative, physics, sgd-theology) is underrated — it is the epistemic prior the whole OS runs on.
